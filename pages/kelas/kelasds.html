Pandas adalah library Python paling fundamental dalam ekosistem Data Science. Hampir tidak ada proyek analisis data yang tidak menggunakan Pandas. Library ini menyediakan struktur data seperti DataFrame dan Series yang memudahkan manipulasi, pembersihan, dan eksplorasi data secara efisien.

Di tahap ini kita berfokus pada Preprocess — langkah kritis sebelum data bisa dianalisis. Data mentah di dunia nyata hampir selalu kotor: ada nilai kosong (missing values), tipe data yang salah, duplikat, dan outlier. Pandas menyediakan tool untuk menangani semua itu.

🗂️ DataFrame & Series

DataFrame adalah tabel dua dimensi (baris × kolom). Series adalah satu kolom. Keduanya adalah tulang punggung struktur data Pandas.

🧹 Handling Missing Values

Gunakan df.isnull(), df.dropna(), atau df.fillna() untuk mendeteksi dan menangani nilai kosong secara strategis.

🔀 Filtering & Slicing

Seleksi data dengan kondisi: df[df['kolom'] > 100] atau df.loc[] / df.iloc[] untuk akses berbasis label dan indeks.

📊 GroupBy & Aggregasi

df.groupby('kategori').mean() — mengelompokkan data berdasarkan kategori lalu menghitung statistik agregat seperti mean, sum, count.

import pandas as pd

# Load dataset
df = pd.read_csv('penjualan.csv')

# Lihat 5 baris pertama
df.head()

# Cek missing values
df.isnull().sum()

# Isi missing values dengan median
df['harga'] = df['harga'].fillna(df['harga'].median())

# Filter: hanya produk dengan penjualan > 100
df_top = df[df['penjualan'] > 100]

# Rata-rata penjualan per kategori
df.groupby('kategori')['penjualan'].mean()
